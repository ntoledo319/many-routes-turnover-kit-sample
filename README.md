# Turnover Kit — free sample sheets

Four sheet types for a fictional two-bedroom cottage, exactly as Turnover Kit generates them: the timed cleaner sheet, the host handover/inspection sheet, the restock par sheet and the damage/missing report. Letter and A4 PDFs plus a read-only HTML view. No sign-in, forms, analytics or email capture.

Three 110-second captioned walkthroughs in walkthroughs/ use the actual sample PDF excerpts, with text transcripts and WebVTT captions. Created by the Turnover Kit project with AI assistance. All property data is fictional; no actual cleaning-speed or inventory-automation claim.

The paid kit (an offline HTML generator that prints these for your own property) is not in this repository. See LICENSE.txt for what you may do with these samples.
