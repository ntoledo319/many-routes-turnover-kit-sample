# Turnover Kit — free sample sheets

Four printed sheets for a fictional two-bedroom cottage, exactly as Turnover Kit generates them: the timed cleaner sheet, the host handover/inspection sheet, the restock par sheet and the damage/missing report. Letter and A4 PDFs plus a read-only HTML view. No sign-in, forms, analytics or email capture.

The paid kit (an offline HTML generator that prints these for your own property) is not in this repository. See LICENSE.txt for what you may do with these samples.
